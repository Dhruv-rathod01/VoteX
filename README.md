# 🗳 VoteX

A web-based Online Voting System developed using HTML, CSS, JavaScript, Firebase Firestore, and deployed using Vercel.

## 📌 Features

* Secure Online Voting Portal
* One Mobile Number = One Vote
* Indian Mobile Number Validation
* Real-time Vote Storage using Firebase Firestore
* Professional Election Commission Inspired UI
* Admin Dashboard
* Live Vote Count
* Party-wise Vote Analytics
* Automatic Winner Calculation
* Responsive Design

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Firebase Firestore
* Git & GitHub
* Vercel

## 🏛 Political Parties Included

* BJP
* Congress
* AAP
* BSP
* SP

## ⚙️ How It Works

1. User enters Name and Mobile Number.
2. User selects a political party.
3. System validates the mobile number.
4. System checks whether the mobile number has already voted.
5. If not voted before, the vote is stored in Firebase Firestore.
6. Admin Dashboard fetches all votes and displays:

   * Total Votes
   * Party-wise Votes
   * Winner Party
   * Voter Records
